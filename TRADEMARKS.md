# Names and logo

The licence covers Ferrite's code. This page covers its names and logo.

- "Ferrite", "Ferrite Console", "Ferrite Pocket" and the Ferrite logo mean the releases FerriteFW publishes.
- You may change the code and run your own build for any noncommercial use: the licence allows it.
- A changed build needs its own name. Say it's unofficial, built from Ferrite, and not supported by the Ferrite project. Leave the logo off.
- Your own build of unchanged code is fine for your own radio. It shows "Unofficial build" on About: that's expected.
- Talking about Ferrite is welcome: reviews, videos, screenshots, guides, "works with Ferrite". So is using the logo to point at the project.

Why: when someone reports a bug or reads a review, "Ferrite" should mean the same thing for everyone. Better still, send your changes back ([CONTRIBUTING.md](CONTRIBUTING.md)), so everyone gets them.

Questions: ask on the [Discord](https://discord.gg/fYygBVD2Kx) or open an issue.
